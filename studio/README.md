# BRUIS Studio (prototype)

A one-page site for an AI-assisted branding and content studio for local businesses, run inside a shared 10 hours a week.

- **Packages**: Brand starter €2,900, Website €2,500 (up to 5 pages), Monthly content €900/month (8 posts, 1 newsletter, simple ads; 3-month minimum). Prices excl. VAT.
- **Price picker**, how a month works, capacity (three monthly clients at a time), FAQ, contact form.
- Prototype: nothing is sold, booked or sent.

One file: `index.html`.
