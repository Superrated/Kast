# BRUIS Speakers (prototype)

A one-page site for an active 2-way stand-mount speaker pair with a solid old oak front, €1,495 the pair.

- **Configurator**: cabinet colour, oak oil, amplifier (Twee with DSP boards and a 24 V adapter, or Twee Reference with Hypex FusionAmp for +€800), oak stands, delivery and set-up by postcode from 8501.
- **Specs, how it's made, listening sessions in the workshop, FAQ** (CE, Recupel).
- Prototype: nothing is sold, reserved or paid.
