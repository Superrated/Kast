# BRUIS Acoustics (prototype)

A one-page site for measured acoustic treatment: measure the room, design, make panels in the workshop, hang them, measure again.

- **Room check**: room size, use, floor, ceiling, furniture and panel type give an estimated ringing time (Sabine), the m² of panels needed and a price.
- **Panels**: oak slats on felt (from €230/m² hung), fabric panels (from €160/m²), ceiling clouds (from €250/m²). Smallest job €900; measurement €150, taken off the order.
- Homes and businesses; fire-rated materials (at least B-s2, d0) for public spaces.
- Prototype: nothing is sold, booked or sent.

One file: `index.html`.
